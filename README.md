## 🌟 Sobre o Projeto

Este repositório contém o código-fonte do meu portfólio profissional. O projeto foi estruturado do zero com foco em **experiência do usuário (UX)**, **design limpo com estética dark mode**, **animações fluidas** e **alta performance de carregamento**. 

A aplicação utiliza o **Next.js App Router** para roteamento inteligente no lado do servidor, componentes modulares reutilizáveis e uma integração dinâmica com a **API do GitHub** para exibição automática de repositórios e projetos recentes.

---

## ✨ Principais Funcionalidades & Tecnologias

- **Framework Moderno:** Construído com **Next.js (App Router)** e **TypeScript** para garantir tipagem estática e otimização de SEO.
- **Layout Baseado em CSS Grid & Flexbox:** Alinhamento milimétrico de colunas (`main` e `aside`) com comportamento responsivo adaptado para dispositivos móveis e desktops.
- **Animações em Cascata (`FadeIn`):** Utilização do **Framer Motion** para criar efeitos de surgimento escalonado (`staggered delay`) nas seções e cards.
- **Design System Customizado (`Glassmorphism`):** Cartões translúcidos com efeito de desfoque (`backdrop-filter`) e bordas suaves integradas ao tema escuro.
- **Efeito de Fundo Orgânico ("Gel Fluido"):** Implementação avançada em CSS puro utilizando gradientes radiais, filtros de desfoque e animações de keyframes simulando um fluido dinâmico e sutil no background.
- **Consumo de API Externa:** Integração assíncrona com os endpoints do GitHub para listagem automatizada de projetos públicos.

## ⚙️ Como Executar o Projeto Localmente

Certifique-se de ter o **Node.js** instalado em sua máquina.

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/nome-do-repositorio.git
   ```

2. **Entre na pasta do projeto:**
   ```bash
   cd nome-do-repositorio
   ```

3. **Instale as dependências:**
   ```bash
   npm install
   ```

4. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

5. Acesse `http://localhost:3000` no seu navegador favorito.
